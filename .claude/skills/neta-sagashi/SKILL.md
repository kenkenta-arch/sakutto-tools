# ネタ探し

## 目的
これから2〜8週間で検索が増えそうで、ブラウザだけで作れるツールのテーマを見つけ、ideas.md に先回りで追加する。

## 調べ方（毎回同じ）
1. 今日の日付から、2〜8週間先の季節行事・制度の締め切り・年度の切り替わりを書き出す（例：12月→年末調整・お年玉・年賀状・大掃除、1月→厄年・成人式・確定申告の準備、3月→卒業・引っ越し）
2. WebSearch（standard）で、それぞれ「〇〇 計算」「〇〇 早見表」「〇〇 シミュレーター」を調べ、上位にあるツールサイトを確認する
3. 候補ごとに次の4点で判定する
   - 検索されそうか（季節性・毎年くり返すか）
   - ブラウザだけで作れるか
   - 正確さの責任が重すぎないか（税金・社会保険料・医療・法律は、公的な出典で毎年の数字を確認できる場合だけ。迷ったら作らない）
   - 上位のツールに弱点があるか（広告だらけ・スマホで見づらい・入力が多い）
4. 確かめられないことは書かない。結論ごとに出典URLを付ける

## 記録のしかた
- `research/neta.md` の一番下に `## YYYY-MM-DD` の見出しを足し、「前回から変わったこと（3行まで）」→「今回の候補（テーマ・時期・判定・出典URL）」の順で書く
- 前の回の記録は消さない・書き換えない。新しい候補がなければ「変化なし」の1行
- 判定が○の候補は、`ideas.md` の「季節ネタ（期限つき）」に「いつまでに公開したいか」を添えて足す。すでにあるものは足さない

## 終わったら
- main に直接コミットして push する（ツール本体ではなく記録だけなので）
- オーナーへの報告は、新しく足した候補を3行以内で

## 更新のルール
- オーナーが「今の直し方も、手順書に足しといて」と言ったら、直し方を1行で書き足す（書き足す前に、その1行を見せる）
