# 切り抜き攻略本

オーナーはSNS投稿の経験がない。専門用語を使わず、1つずつ短く伝える。
数字や「伸びるコツ」は、ほとんどがツール会社のブログ由来で公式データではない。**自分の成績で確かめて、この本を書き換えていく**のが前提。

## 1. キャンペーンを選ぶとき（全部OKのものだけ参加）
- [ ] 参加が無料（お金を払わせるものは詐欺として扱う）
- [ ] 配信者・権利者本人が募集している（許可がはっきりしている）
- [ ] 日本語の切り抜き・日本のアカウントでも対象か（ルールに書いてなければ、参加前に運営に質問）
- [ ] 日本から報酬を受け取れるか、手数料はいくらか
- [ ] 報酬の単価（1,000再生あたり）・1本あたりの上限・残りの予算
- [ ] 投稿先（TikTok / Instagram / YouTube）と、禁止事項（音楽の差し替え禁止、透かし必須など）
- 迷ったら参加しない。ルールのスクショをオーナーに送ってもらって判定する

## 2. 切り抜きの作り方
- **最初の1〜3秒で止める**：一番おもしろい瞬間を先頭に持ってくる（元の配信の頭から始めない）
- **長さ**：まずは20〜45秒で作り、成績を見て調整する
- **字幕は必須**：音なしで見る人が多い。大きく読みやすく
- **冒頭テロップ（ひとこと）**：何が起きるか気になる一文を画面上部に（例：「この後まさかの展開」はありがちなので、具体的に）
- **自分の一言を足す**：テロップで短い感想・解説を入れる。ただ切っただけの動画は、YouTubeの「再利用コンテンツ」扱いで広がりにくい
- **ループ**：最後が最初につながると、くり返し見られやすい
- 1本の配信から、テイストの違う切り抜きを複数作る（名場面・笑い・攻略のコツ・ニュース）
- 同じ型の動画を大量に連投しない（スパム扱いを避ける）

## 3. 投稿のしかた（オーナーが手動で行う）
- 投稿はスマホのアプリから。1本1〜2分
- キャンペーンのルールに書かれた必須事項（タグ、メンション、説明文）を必ず入れる
- 説明文：何の動画かわかる言葉を入れる（TikTokは検索でも見られる）
- 投稿時間：「この時間が最強」という決まった答えはない。最初の2週間は時間帯を変えて試し、成績で決める
- 投稿したら、キャンペーンのサイトに投稿のURLを提出する

## 4. 成績の記録と改善
- 投稿ごとに記録する：日付・時間・キャンペーン・内容の型（名場面/笑い/攻略/ニュース）・長さ・冒頭テロップ・24時間後の再生数・48時間後の再生数・承認されたか・報酬
- 週に1回、伸びたものと伸びなかったものを比べ、**伸びた型を増やし、伸びない型を減らす**
- わかったことは、この攻略本の該当する場所に1行で書き足す（書き足す前にオーナーに見せる）

## 5. お試し期間のルール
- 開始から2週間で判定：報酬が出たか、時間に見合うか
- 見合わなければやめて、ツールサイトに集中する

## 更新のルール
- オーナーが「今の直し方も、攻略本に足しといて」と言ったら、直し方を1行で書き足す（書き足す前に、その1行を見せる）
