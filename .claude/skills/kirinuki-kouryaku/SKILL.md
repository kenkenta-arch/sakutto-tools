# 切り抜き攻略本

オーナーはSNS投稿の経験がない。専門用語を使わず、1つずつ短く伝える。
数字や「伸びるコツ」は、ほとんどがツール会社のブログ由来で公式データではない。**自分の成績で確かめて、この本を書き換えていく**のが前提。

## 0. アカウント作りの方針（キャンペーンが終わっても残る資産にする）
- アカウントは「ゲームの名場面と最新情報」のような**ジャンルのアカウント**にする。アカウント名・プロフィールにキャンペーン名や会社名を入れない
- 作る順番：TikTok（日本語）→ Instagram・YouTube（日本語）→ 慣れたら英語版。**言語ごとにアカウントを分ける**
- 同じ動画は TikTok・Instagram・YouTube の3か所に投稿してよい（キャンペーンのルールで禁止されていなければ）。同じアカウントに同じ動画を2回出さない
- 日本語版と英語版は字幕と冒頭テロップを作り分ける（翻訳はClaudeが行う）。1人が登録できるアカウント数・重複提出のルールは参加時に確認する
- 毎回「自分の一言」を入れて、キャンペーンが変わってもファンが残る切り口を作る
- プロフィールのリンクは、ゲーマー向けツールが揃ってから「まとめページ」に向ける
- 将来の収入源：キャンペーン報酬（今すぐ）→ ツールサイトへの送客 → 各SNSの収益化（条件を満たしたら）→ ゲーム関連のアフィリエイト

### 決定したプロフィール（2026-11-24）
- 表示名：ゲームの瞬間｜GAME MOMENTS（英語版は GAME MOMENTS）
- @ID：game_moments_jp（予備：gamemoments_jp → game.moments.jp → gamemoments.jp）。英語版は game_moments（なければ game_moments_en）
- アイコン：紫〜ピンクのグラデーションに白いコントローラーと「MOMENTS」の文字（案C）
- プロフィール文：「🎮話題のゲームの名場面を毎日1分で／ひとことツッコミ付き｜新作・神プレイ・最新情報／フォローで見逃さない👇」
- リンク：最初はなし。サクッと便利ツールにゲーマー向けツールが3〜5個揃ったら「ゲーマー向けツールまとめページ」を作ってリンクする（TikTokはフォロワー1,000人から貼れる）。キャンペーンのルールでリンクが禁止されていないかも確認する
- TikTok：作成済み（2026-11-24）
- Instagram：ユーザーネーム game_moments_jp／名前「ゲームの瞬間｜ゲーム切り抜き・最新情報」（名前欄は検索対象・14日間で2回まで変更可）／自己紹介「🎮話題のゲームの名場面を毎日お届け／ひとことツッコミ付きで1分で楽しめる／新作トレーラー｜神プレイ｜最新情報／▶︎TikTokでも毎日投稿中 @game_moments_jp」
- YouTube：チャンネル名「ゲームの瞬間｜GAME MOMENTS」／ハンドル @game_moments_jp／ブランドアカウントで作る／説明文は検索対象なので「ゲーム・名場面・最新情報・トレーラー」を自然に入れる
- 3つのSNSで@IDをそろえる。違うIDになったらプロフィール文の相互リンクを直す
- 参考にした成功例：@gaming（Gamelancer社・話題のゲームの切り抜きを集めて約1,000万フォロワー、複数アカウント展開、企業案件）、@zeff_gaming（ゲームニュース）、@rapidreacts（プロフィールに仕事の連絡先）
- フォロワーが増えたら、プロフィールに仕事用の連絡先（専用のメールアドレス）を追加する

## 1. キャンペーンを選ぶとき（全部OKのものだけ参加）
- [ ] 参加が無料（お金を払わせるものは詐欺として扱う）
- [ ] 配信者・権利者本人が募集している（許可がはっきりしている）
- [ ] 日本語の切り抜き・日本のアカウントでも対象か（ルールに書いてなければ、参加前に運営に質問）
- [ ] 日本から報酬を受け取れるか、手数料はいくらか
- [ ] 報酬の単価（1,000再生あたり）・1本あたりの上限・残りの予算
- [ ] 投稿先（TikTok / Instagram / YouTube）と、禁止事項（音楽の差し替え禁止、透かし必須など）
- 迷ったら参加しない。ルールのスクショをオーナーに送ってもらって判定する

## 2. 見本を先に集める（一番大事）
- 「いい感じにして」では仕上がりは良くならない。**必ず見本を渡してから作る**
- 一番いい見本は、**参加するキャンペーンで実際に伸びている切り抜き3〜5本**（同じ配信者・同じ視聴者で結果が出ているため、一般的なコツより正確）
- 見本は「参考」フォルダに入れてもらう（動画ファイル、URL、スクショのどれでも可）
- 見本を分析して、次を `参考/スタイル.md` に書き出してから作業する
  - 冒頭の1〜3秒で何を見せているか、冒頭テロップの言い方
  - 字幕の大きさ・位置・色・縁取り・1行の文字数・出し方
  - 長さ、カットの間隔（テンポ）、ズームや効果音の使い方
  - 最後の終わり方（ループするか）
- 見本の動画そのものは素材として使わない（スタイルを学ぶだけ）
- 一般的なツール会社（OpusClip、Vizard、Submagicなど）のバズ度スコアは中身が非公開で有料のため使わない。公開されているコツは下の「切り抜きの作り方」に取り込み済み

## 3. 切り抜きの作り方
- まず `参考/スタイル.md` に合わせる。下の一般的なコツと食い違ったら、見本のほうを優先する
- **最初の1〜3秒で止める**：一番おもしろい瞬間を先頭に持ってくる（元の配信の頭から始めない）
- **長さ**：まずは20〜45秒で作り、成績を見て調整する
- **字幕は必須**：音なしで見る人が多い。大きく読みやすく
- **冒頭テロップ（ひとこと）**：何が起きるか気になる一文を画面上部に（例：「この後まさかの展開」はありがちなので、具体的に）
- **自分の一言を足す**：テロップで短い感想・解説を入れる。ただ切っただけの動画は、YouTubeの「再利用コンテンツ」扱いで広がりにくい
- **ループ**：最後が最初につながると、くり返し見られやすい
- 1本の配信から、テイストの違う切り抜きを複数作る（名場面・笑い・攻略のコツ・ニュース）
- 同じ型の動画を大量に連投しない（スパム扱いを避ける）

## 4. 投稿のしかた（オーナーが手動で行う）
- 投稿はスマホのアプリから。1本1〜2分
- キャンペーンのルールに書かれた必須事項（タグ、メンション、説明文）を必ず入れる
- 説明文：何の動画かわかる言葉を入れる（TikTokは検索でも見られる）
- 投稿時間：「この時間が最強」という決まった答えはない。最初の2週間は時間帯を変えて試し、成績で決める
- 投稿したら、キャンペーンのサイトに投稿のURLを提出する

## 5. 成績の記録と改善
- 投稿ごとに記録する：日付・時間・キャンペーン・内容の型（名場面/笑い/攻略/ニュース）・長さ・冒頭テロップ・24時間後の再生数・48時間後の再生数・承認されたか・報酬
- 週に1回、伸びたものと伸びなかったものを比べ、**伸びた型を増やし、伸びない型を減らす**
- わかったことは、この攻略本の該当する場所に1行で書き足す（書き足す前にオーナーに見せる）

## 6. お試し期間のルール
- 開始から2週間で判定：報酬が出たか、時間に見合うか
- 見合わなければやめて、ツールサイトに集中する
