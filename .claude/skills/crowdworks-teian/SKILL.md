# クラウドワークスの案件探しと応募文

オーナーはプログラミング未経験の学生。作業（動画・資料・ツール）はClaudeが作り、オーナーは応募の送信・やりとり・最終チェックを行う。
**オーナーの名前・年齢などの個人情報は、このファイル（公開リポジトリ）に書かない。** 応募文では空欄にして、本人に書き換えてもらう。

## 1. 案件の探し方
- 公開ページ https://crowdworks.jp/public/jobs/search?hide_expired=true&order=new&search%5Bkeywords%5D=キーワード を Playwright で開いて集める（cw-assets.crowdworks.jp の読み込みが必要）
- Claudeが最後まで作れるものを優先：切り抜き・ショート動画編集、図解アニメ、Webページ制作、スプレッドシート/GAS、データ整理、画像加工
- 目安：報酬が相場以上（ショート動画なら1本2,000円以上）、応募数が少ない、締切まで余裕がある

## 2. 見送る案件（よくある危ないパターン）
- 未経験OKなのに月20万円以上など、報酬が不自然に高い。似た文面の募集が大量に出ている
- すぐに「サービス外連絡」（LINEなど外部）へ移ろうとする、本人確認なし・実績なし
- あとで有料の講座・ツールを買わせる気配がある（お金を払う話が出たら即断る）
- 依頼者の評価が低い（3.5未満）、プロジェクト完了率が低い（70%未満）
- 1本数百円などの極端に低い単価、Premiere Pro などオーナーが持っていないソフトが必須
- AI利用が禁止されている、「AI以外の実績」が条件
- 規約違反の内容（出会い系の自動化、スクレイピングでの大量収集、成人向け など）

## 3. 応募文の作り方
- 1行目は「表紙」：相手が欲しい結果を約束する一文（例：「【最初の1.5秒で止める切り抜き】を作るのが得意です。」）
- 依頼者が指定したテンプレートがあれば、項目・順番を必ずそのまま守る（守らないと即不採用になる）
- できることを盛らない。AIやツールを使って制作していることは隠さず、「AIとツールを組み合わせた制作環境」と書く
- 依頼者の書いた言葉（目的・テイスト・見る人）を拾って、「理解している」ことを示す
- 不明点・確認したいこと（納品形式、プロジェクトファイルの形式など）は質問として最後に入れる
- AIっぽさを消す：丁寧すぎる定型文、同じ言い回しの繰り返し、大げさな表現を避ける。短い文で、具体的に
- 個人情報の欄（名前・年齢・面談候補日）は（　）で空けておく
- オーナーの予定：月・火は18時まで、水は16時15分まで学校。木〜日は比較的時間がとれる（面談候補日はこの範囲で）

## 4. 応募したら
- research/crowdworks.md に「案件ID・内容・報酬・応募日・結果」を1行追記する
