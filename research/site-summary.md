# 各ツールの作りの決まり
- 1ページ1ツール。title と meta description に検索されそうな言葉
- 「使い方」「よくある質問」の文章を必ず入れる
- スマホ幅375pxで確認、Playwrightで計算結果をテスト（別の方法で計算した答えと一致を確認）
- お金・法律・健康に関わるものは注意書き、公式情報へのリンク
- 広告用の空き枠（AD_SLOT）をページの真ん中に置いている
- オープンソースはMIT/Apache/BSDのみ。CDNはバージョン固定、なるべく同じサイト内に置く
- デザイン：白いカード型、青のアクセント、ダークモード対応、絵文字は少し
